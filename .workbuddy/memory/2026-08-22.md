## 2026-08-22（续）修复快捷键录入不生效
- 根因：HotkeyInputManager.beginSystemCapture 复用 start() 的 globalMonitor/localMonitor，endSystemCapture 把常驻监听一并移除置 nil → 录制新快捷键后 NSEvent 监听链路被摧毁，只剩 Carbon RegisterEventHotKey 兜底（失败时静默）；且无取消途径、无修饰键的按键会被吞并卡死在录制态。
- 修复：录制用独立 captureGlobalMonitor/captureLocalMonitor + captureCompletion/captureCancelHandler；Esc 取消；要求 ⌘/⌃/⌥/⇧ 至少一个（排除 F 键隐式 .function 误判）；endSystemCapture 末尾兜底调 start() 确保常驻监听存活。SettingsView 调用处同步改为 onCancel/onComplete。
- 已重建重启（pid 46054），待用户手动验证。

## 2026-08-22（续6）修复「开始录音即闪退」
- 崩溃：EXC_BREAKPOINT / dispatch_assert_queue_fail，栈在 SpeechManager.startLocalRecording 的 installTap 闭包。
- 根因：Swift 6 下在 @MainActor 方法内传给 ObjC API 的非 @Sendable 闭包继承主线程隔离；AVAudio 在实时音频线程回调 → dispatch_assert_queue 触发 SIGTRAP。
- 修复：①两处 installTap 闭包显式 @Sendable（参数标签是 block: 不是 tapBlock:）②新增 MainActorEventSink<T>（@unchecked Sendable + UnsafeSendableBox 装箱转移）把音频电平/分段结果/识别结果投递回主线程③recognitionTask resultHandler 同样改 @Sendable+sink④updateAudioLevel 加 nonisolated。
