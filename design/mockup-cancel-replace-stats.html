SoundIn · 三项新功能设计稿

取消录音 / 替换选中内容 / 每日听写统计。以下为交互与界面示意，确认后再进入开发。

1取消录音

录音中（进度条正常走）
识别中 42% ESC 取消
录音期间胶囊右侧常驻 ESC 取消 提示
（仅录音阶段显示，转写阶段不显示）
按下 ESC 后 · 约 0.8 秒自动消失
✕ 已取消
红圈 ✕ + 「已取消」，不粘贴、不计入字数统计
  • 触发：Esc，仅在录音中生效（长按 / 单击模式均可）
  • 转写进行中按 Esc 不响应（此时马上就出结果了，避免误触丢结果）
  • 单击模式下「再按一下热键」仍然是结束并转写，语义不变

2替换选中内容

目标应用里有选中文本时开始录音
将替换选中的内容
识别中 68% ESC 取消
  • 开始录音瞬间通过辅助功能 API 读取焦点应用的选中文本：有选中 → 胶囊上方浮出绿色提示条「将替换选中的内容」
  • 松手后直接 ⌘V —— macOS 原生行为就是粘贴覆盖选中，无需先删后粘，最快且兼容性好
  • 没有选中文本 → 与现在完全一致，光标处插入
  • 依赖辅助功能权限（应用已在用，无需新授权）；读不到选区信息的应用自动退回插入模式

3每日听写字数统计

触发方式长按说话 >
今日听写新增1,284 字 · 本周 6,032 字
开机时启动开
统计口径：成功输入的转写字符数（去除空白），取消的录音不计入；数据仅保存在本机。
  • 位置：设置 → 通用页，「语音输入」分组内一行，默认展示「今日 + 本周」
  • 计数在粘贴成功后累加（剪贴板兜底路径同样计入）
  • 存储用 UserDefaults，按日期键滚动，自动清理 90 天前的旧数据
