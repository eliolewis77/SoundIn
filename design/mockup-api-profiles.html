④升级迁移（无感）

首次启动新版时：如果检测到旧的单独 Base URL / Key / 模型设置，自动打包成一个名为「默认」的配置档，识别和润色的原选择保持不变。之后旧字段不再使用，统一走配置档。
配置档以 JSON 存在 UserDefaults（与现状一致）；API Key 仍是明文存储，安全等级不降低也不提高。
