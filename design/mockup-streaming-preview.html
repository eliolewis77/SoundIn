SoundIn · 流式实时预览 设计稿（方案 A）

录音转写（API 模式）时，把「正在识别的最新文字」实时显示出来，而不是等松手才一次性甩出整段。通用页加一个独立开关，默认关，不影响现有行为。下面两块：① HUD 录制态怎么显示实时文字；② 通用页新增的开关。末尾有两个需要你拍板的设计点。

1HUD 录制态：实时文字预览

● 录音中识别…
当前：只有波形 + 进度，文字要等结束
今天下午去超市买了点东西，顺便▋
● 录音中实时转写…
新方案：波形上方多一行实时文字（无省略号）
分段节奏（引擎侧）：API 转写按段返回，预览段每 4 秒强制切一段；若某段已达 8 秒且末尾静音 ≥0.45 秒则自然切段。即文字是「一段段刷新」而非逐字流动——这是 Whisper 类 API 的固有粒度，先讲清楚避免预期偏差。

?两个需要你定的点

① 胶囊尺寸：现在悬浮窗是 136×72 的小胶囊，塞一行实时文字会非常挤。 两种处理——
· A：录制中胶囊自动「长高」（如变 136×116），放下波形 + 一行文字，松手恢复 72 高；
· B：胶囊保持原样，实时文字显示在胶囊正上方一条单独的浮条里（像字幕）。
我倾向 B（不动原胶囊尺寸，视觉更稳，字幕感也更符合"实时"），但 A 更紧凑。

② 文字来源：API 模式是「整段返回」，所以显示的会是「最近一段的识别结果」并随新段覆盖，不是真正逐字流动。本地模式则是逐字。要不要给 API 模式的预览也标注一个"转写中…"的临时态？默认我会标。
